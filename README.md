# Прозор

Адаптивный MVP-прототип личного кабинета жителя коттеджного поселка / ТСН. Он воплощает главный сценарий ТЗ: за пару минут увидеть работы, деньги и действия, требующие внимания.

## Запуск

Требуется Node.js 20+.

```bash
npm install
npm run dev
```

Vite выведет локальный адрес приложения. Для production-сборки используйте `npm run build`; для проверок — `npm test`.

## Что реализовано

- Dashboard жителя: актуальные работы, важное объявление, персональные действия и финансовая сводка.
- Разделы проектов, финансов, заявок и документов.
- Карточка проекта с прозрачной связью бюджет → траты → готовность → последнее обновление.
- Создание демонстрационной заявки; навигация и модальные карточки работают без сервера.
- Mobile-first интерфейс с нижней навигацией на смартфонах.

## Структура

- `index.html` — единственная точка подключения приложения.
- `src/main.js` — запуск, рендер экранов и UI-события.
- `src/data.js` — демонстрационные доменные данные и форматирование денег. При подключении API замените этот модуль репозиториями запросов.
- `src/styles.css` — адаптивная дизайн-система и все стили.
- `tests/` — быстрые проверки доменных данных.

## Как безопасно развивать

Следующим шагом подключите REST API: вынесите загрузку каждого ресурса из `src/data.js` в отдельный модуль, например `src/api/projects.js`, сохранив форму объектов, которую используют экраны. Сервер должен ограничивать данные по `communityId` и RBAC; UI не должен быть единственным уровнем проверки доступа.
